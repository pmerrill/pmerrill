## About

I'm a Minnesota-based engineer building reliable software for healthcare systems. My career started in 2011 and has spanned healthcare, sports, and consumer tech.

2021 brought the move to [RxAnte](https://rxante.com) and pharmacy workflow systems for patients with complex medical needs. In that time, I've re-architected integrations to support 6x program growth and built clinical decision tools that improved patient outcomes.

Across all of it, the focus is API design, architecture, and replacing manual processes with reliable, well-tested systems.

## Projects

### [Football Trade Trees](https://footballtradetrees.com)

An archive of every NFL trade from 1920 to the present — roughly 4,000 trades, built with AI agents. It visualizes the original deal through each re-trade to the player it became.

### [Chomp Foods API](https://chompthis.com/api)

SaaS nutrition database API serving 900K+ foods (28M+ records) to health & fitness apps, with &lt;100ms response times on a LEMP stack with Redis caching and optimized MySQL queries. [Architecture deep-dive →](https://github.com/pmerrill/Chomp-Foods-API-Architecture)

### [College Hockey Dynasty](https://collegehockeydynasty.com)

A from-scratch iOS GM sim for college hockey, built in Swift — a game engine with fatigue and line chemistry, NIL-era recruiting and dual-budget finances, and tournament seeding on the NPI ranking formula.

## Impact

* **Reliability (RxAnte):** Built synchronization systems maintaining &lt;0.1% error rates for critical patient data workflows.
